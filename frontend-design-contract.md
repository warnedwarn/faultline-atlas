# Frontend Design Contract

## screenArchitecture

Map-first-world.

## aboveTheFold

The user lands inside a municipal contour map. Four sector plates, a fault-pressure ring, a narrow dispatch rail, and the move composer are visible without a marketing hero.

## primaryInteraction

Select a sector, write one concrete response move, dispatch it to validators, and watch the accepted effect travel across the shared map.

## layoutMap

A narrow left dispatch rail, a large irregular center map, a right pressure instrument, and a bottom transaction tape. Mobile collapses to map, instruments, then composer.

## visualMetaphor

A marked-up seismic emergency atlas used during a live municipal drill.

## motionSystem

Contour Drift moves the canvas field. Pressure Pulse expands from the active sector. Dispatch Slide inserts new records. Validator Sweep crosses the transaction tape. Sector Shockwave signals accepted state changes.

## effectStack

Device-pixel-ratio-aware contour canvas and layered CSS fault traces.

## componentShapeLanguage

Square survey controls, clipped dispatch slips, circular instruments, and irregular map plates.

## customVisualComponents

ContourField, SectorPlate, PressureRing, DispatchRail, ConsensusTransit.

## bannedFromThisBuild

No centered hero, equal feature cards, stats strip, chip row, form-to-feed skeleton, three-column footer, generic navy-purple gradient, or decorative browser chrome.

## proofOfDifference

Unlike Replication Notebook's paper workspace and Patch Semaphore's release control surface, this is a single spatial map. Its state is represented by geographic pressure, not document rows or software gates.
