# README Design Contract

## readmeArchetype

Field report.

## readmeNarrativeVoice

Municipal incident commander writing a concise exercise dispatch.

## readmeSectionPattern

Dispatch header, map legend, exercise protocol, chain record, drill procedure, after-action limits.

## readmeMotif

Annotated emergency map folio.

## requiredFactsPlacement

Identity and links sit in the dispatch header. State and methods live in the legend and protocol. Consensus and guards appear as exercise doctrine. Setup and testing use drill procedure. Limitations close the after-action note.

## bannedReadmePatterns

No generic feature introduction, default technology stack section order, product-manual voice, or README badge row.

## proofOfDifference

The preceding two projects use a research notebook and a software release ledger. This document opens as an operational dispatch and organizes technical facts as map annotations and drill doctrine.
